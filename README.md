# 计算机学习库

这是一个面向学生的计算机知识学习项目。内容按技术方向组织，目前包含：

- `后端/`
- `前端/`
- `嵌入式/`
- `数据结构与算法/`

以后可以按实际需要增加语言、框架、中间件、计算机基础等大类。新增内容由项目级 Skill `.agents/skills/computer-learning-library/` 统一约束。

## 推荐目录结构

```text
大类/
└── 可选的中间分类/
    └── 知识点名称/
        ├── 知识详解.md
        └── 示例代码.<合适的扩展名>
```

如果一个主题需要多个代码文件，可以使用 `示例代码/` 目录，但其中必须包含明确的运行入口和必要说明。

## 内容原则

1. 先判断知识点属于哪个大类，再决定是否需要中间分类。
2. 中间分类只用于聚合同一稳定主题下的多个知识点，不为单个知识点机械增加层级。
3. `知识详解.md` 应从概念、原理、使用场景、关键流程、常见误区和实践建议等方面形成完整讲解。
4. 示例代码必须服务于讲解，能够运行或验证，并用详细注释解释关键步骤、设计原因和预期结果。
5. 讲解与代码中的术语、流程和结论应保持一致。

## 示例

```text
后端/
└── 数据库/
    └── MySQL事务隔离级别/
        ├── 知识详解.md
        └── 示例代码.sql
```

这里的 `数据库` 是多个相关知识点共享的中间分类；如果暂时只有一个孤立主题且没有明确归组，不必强行增加这一层。

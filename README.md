# 计算机学习库

这是一个面向学生的计算机知识学习项目。内容按技术方向组织，目前包含：

- `后端/`
- `前端/`
- `嵌入式/`
- `数据结构与算法/`

以后可以按实际需要增加语言、框架、中间件、计算机基础等大类。新增内容由项目级 Skill `.agents/skills/computer-learning-library/` 统一约束。

## 推荐目录结构

```text
大类/
└── 可选的中间分类/
    ├── 系列导航.js          # 同系列知识点共享，只在新增知识点时更新这一份
    └── 知识点名称/
        ├── 学习页.html      # 唯一学习载体：知识解析 + 图示 + 互动 + 练习
        └── 示例代码/
            └── 示例代码.<合适的扩展名>
```

单个代码文件也可以直接放在知识点目录下；多个文件时用 `示例代码/` 目录，并附 `README.md` 写明运行命令与预期结果。旧知识点（`知识详解.md` + 互动演示 + 练习四件套）不追溯迁移。

## 内容原则

1. 先判断知识点属于哪个大类，再决定是否需要中间分类。
2. 中间分类只用于聚合同一稳定主题下的多个知识点，不为单个知识点机械增加层级。
3. `学习页.html` 是完整的教学载体：知识解析要讲透（是什么 / 为什么 / 边界与坑 / 与已知体系对照），机制类内容配内联 SVG 图示，浏览器跑不了的验证诚实引导到本地命令，不假装能在线运行。
4. 示例代码必须服务于讲解，能够运行或验证，并用详细注释解释关键步骤、设计原因和预期结果；页面引用的报错与输出以真实运行结果为准。
5. 讲解与代码中的术语、流程和结论应保持一致；不同类型的知识点（语言类 / 服务类 / 工程思维类）侧重不同，细则见项目级 Skill。

## 示例

```text
前端/
└── TypeScript/                      # 稳定系列：11 个知识点共享
    ├── 系列导航.js                  # 系列清单唯一维护点，各页自动挂载互跳
    └── 基础类型与收窄/
        ├── 学习页.html              # 知识解析 + 4 张 SVG 图示 + 互动 + 练习
        └── 示例代码/
            ├── 01-收窄六式.ts
            └── README.md            # 运行命令 + 预期结果（含预期报错）
```

这里的 `TypeScript/` 是多个相关知识点共享的稳定系列；如果暂时只有一个孤立主题且没有明确归组，不必强行增加这一层。

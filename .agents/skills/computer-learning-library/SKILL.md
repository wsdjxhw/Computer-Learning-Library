# 维护计算机学习库

把用户想学习的概念整理成结构清楚、可以独立学习和动手验证的主题资料。

## 先理解现有结构

1. 阅读项目根目录的 `README.md`、`AGENTS.md` 和相关大类下已有目录。
2. 搜索是否已有相同或高度重叠的知识点，优先补充或重构现有内容，避免重复建档。
3. 保留用户已有内容和目录命名；除非用户明确要求，不做与当前主题无关的大规模迁移或改名。

## 确定存放位置

1. 根据知识点的核心用途选择最合适的大类，而不是仅凭出现的编程语言判断：
   - 服务端开发、数据库、分布式、服务端框架或中间件通常归入 `后端/`。
   - 浏览器、Web UI、客户端交互和前端框架通常归入 `前端/`。
   - 单片机、RTOS、驱动、硬件接口和嵌入式开发通常归入 `嵌入式/`。
2. 如果现有大类确实不合适，创建语义明确的新大类；不要把明显不相关的内容硬塞进现有目录。
3. 只有当两个或以上知识点共享一个稳定主题时，才在大类下建立中间分类，例如 `后端/数据库/`。若新主题预期将自然形成系列，也可以先建立中间分类，但要避免只有形式、没有聚合作用的层级。
4. 一个知识点使用一个名称清晰的独立目录。目录名优先采用学习者熟悉的中文术语，必要时保留标准英文名称或缩写。
5. 主题跨多个方向时，选择承担主要讲解的目录作为唯一正文位置；其他方向若确有需要，只放简短索引链接，避免复制两套内容。

## 创建知识点内容

每个知识点目录至少包含以下内容。其中「互动演示」与「练习」两项自本规则加入起执行，**不追溯**已建成的知识点（除非用户明确要求补齐）：

### `知识详解.md`

根据主题合理组织，而不是机械套模板；通常应覆盖：

- 学习目标、前置知识和适用范围。
- 核心概念，以及它解决的问题。
- 原理、关键机制或执行流程；必要时使用表格、步骤或 Mermaid 图帮助理解。
- 与示例代码逐段对应的解释。
- 常见误区、边界条件、失败情形和排查思路。
- 实际应用场景、取舍和可继续学习的方向。
- 运行示例所需的环境、命令和预期结果。

对八股或面试类主题，除了结论，还要解释“为什么”，并补充常见追问；不要只罗列背诵答案。

### 示例代码

1. 至少创建一个真实代码文件，扩展名与主题匹配，例如 `.java`、`.ts`、`.py`、`.go`、`.c`、`.sql` 或 `.html`。
2. 示例必须直接验证正文中的核心概念，保持最小但完整，避免加入无关工程复杂度。
3. 优先让示例可直接运行；若依赖硬件、服务或特定环境，提供可验证的替代方式，并明确说明限制。
4. 注释要面向学习者，解释关键语句做什么、为什么这样写、执行顺序、重要变量和预期现象。不要给每一行添加重复代码字面的低价值注释。
5. 示例有多个文件时，放入 `示例代码/` 目录，并提供该目录的 `README.md`，写明入口、依赖和运行方法；这份说明不能替代真实代码文件。
6. 示例代码与 `知识详解.md` 的术语、步骤和输出必须一致。

### `互动演示.html`（可视化互动网页）

1. 单文件自包含：双击即可在浏览器打开、离线可用；用原生 HTML/CSS/JavaScript 实现，不依赖 CDN、构建工具或本地服务器。
2. 互动必须直接演示或验证该知识点的核心机制——可操作的模拟、可调的参数、即时反馈的可视化；不是静态配图，也不是装饰性动效。页面打开时用一句话告诉学习者「怎么玩」。
3. 界面为中文，术语、流程与 `知识详解.md` 和示例代码严格一致。
4. 确实不适合网页交互演示的主题（如硬件依赖），说明原因并提供替代形式（如交互式自测问答页），不要硬凑动画。

### `练习.md`

1. 题目分层：基础（概念辨析、猜输出）与进阶（应用、排错、编程）搭配，建议合计 5~10 题，优先取材于本知识点示例代码的真实输出与常见陷阱。
2. 编程题给出明确的输入/输出或验收标准，让学习者能自行验证对错；可附代码骨架。
3. 提示与参考答案放在文末或用折叠块（如 `<details>`），不得与题目同屏直接可见。
4. 答案必须自洽：与 `知识详解.md` 和示例代码的实际行为一致。

## 验证与交付

1. 运行或以合适工具验证示例；互动网页须在浏览器中打开并验证核心交互可用（无浏览器环境时至少做静态检查并在交付说明中注明）；练习题逐题核对答案。如果客观上无法运行，进行静态检查，并清楚记录未验证的原因。
2. 检查内部链接、命令、文件名和相对路径是否正确。
3. 检查主题是否被放进最合理的目录、是否出现重复内容、是否错误增加了中间层级。
4. 最终向用户说明主题路径、创建或更新的文件、验证结果，以及任何环境限制。

用户的明确要求优先于本 Skill 的推荐做法；但不得在未说明的情况下省略最低交付物：「知识详解 + 带详细注释的示例代码」为所有知识点必交，「互动演示 + 练习」为新知识点必交（不追溯旧知识点）。

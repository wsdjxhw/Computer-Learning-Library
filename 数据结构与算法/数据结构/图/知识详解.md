## 一、图解决什么问题

前面所有结构表达的要么是"序列"（数组/链表），要么是"层次"（树）。现实世界更多是**网状关系**：社交好友、城市路网、网页超链接、任务依赖。图 = **节点（Vertex）+ 边（Edge）**，只描述"谁和谁有关系"，是最一般的关系模型——树和链表都是图的特例。

- **无向图**：边没有方向（好友关系、双向道路）；**有向图**：边有方向（关注、超链接）。
- **带权图**：边上带数值（里程、耗时、带宽）。
- **环**：从某节点出发能绕回自己。遍历算法必须防环。

## 二、核心原理

### 2.1 邻接表：每个节点一张"邻居清单"

```text
示例图（无向）:            邻接表:
      A                  {  A: [B, C]
    /   \                   B: [A, D, E]
   B     C                  C: [A, F]
  / \    /                  D: [B]
 D   E--F                   E: [B, F]
                             F: [C, E]  }
```

无向边 u–v 要在**两个方向**都登记（A 的清单有 B，B 的清单也有 A）；有向图只登记箭头方向。用"字典 + 列表"实现最自然：查一个节点的邻居 O(1) 定位 + O(度) 展开。另一种表示是邻接矩阵（n×n 的 0/1 表），查"两点是否相邻"O(1)，但存稀疏图浪费 O(n²) 空间——**稀疏图用邻接表，稠密图或需要 O(1) 判邻接时用矩阵**。

### 2.2 BFS：一圈一圈向外扩

从起点出发，先访问所有 1 步邻居，再 2 步、3 步……像水波扩散。靠两件装备实现：

- **队列**：邻居入队排队，保证"离起点近的先被处理"（先进先出）；
- **visited 集合**：图**有环**，不标记已访问会绕圈死循环。

```text
BFS(A) 的扩展层次:      访问顺序: A B C D E F
第 0 层:  A             （逐层推进：先处理完近的才轮到远的）
第 1 层:  B  C
第 2 层:  D  E  F
```

细节：**入队的同时就标记 visited**。若等出队时才标记，同一节点可能被多个邻居重复压进队列。

### 2.3 无权图最短路径：BFS 顺带完成

节点第一次被访问时，它是沿着"当时正在处理的节点"多走一步到达的，而队列保证被处理节点按距离升序排列，所以**第一次到达时的层数就是最少边数**。记录 `dist[邻居] = dist[当前] + 1` 即可：`A→F` 最少 2 步（A-C-F 或 A-B-E-F，BFS 只保证长度最短，不枚举所有等长路径）。

**注意边界**：该结论只对**每条边代价相同**的图成立；边带权重要求改用 Dijkstra（非负权）或 Bellman-Ford（可负权）。

### 2.4 DFS：一条路走到黑，再回头

每到一个节点就**先深入它的一个未访问邻居**，走到无路可走才回溯换路。两种等价写法：

- **递归**：代码最短，调用栈隐式充当"记路"的栈；
- **迭代**：显式用栈。语义与 BFS 恰好相反——**队列先处理老的（横向铺开），栈先处理新的（纵向深挖）**。

```text
DFS(A): A → B → D（无路）回溯 → E → F → C   顺序: A B D E F C
对照 BFS(A): A B C D E F   （按层，不回头）
```

### 2.5 复杂度

| 项目 | 复杂度 | 说明 |
| --- | --- | --- |
| 邻接表存储 | O(V + E) | V 个节点 + E 条边各存两次（无向） |
| BFS / DFS | O(V + E) | 每个节点进出队/栈一次，每条边被查看常数次 |

## 四、常见误区与边界条件

| 误区 / 边界 | 说明 |
| --- | --- |
| 遍历不加 visited | 图有环，立刻死循环；这是图与树遍历最大的差别 |
| 出队/出栈时才标记 visited | 同一节点被重复入队（或重复压栈），队列暴涨；入队即标记（迭代 DFS 弹出时需再查一次） |
| BFS 用于带权图 | 边权不等时"层数最少"≠"代价最小"，要用 Dijkstra |
| 遍历起点不连通 | 从单一起点出发只能访问其连通分量；要覆盖全图需对每个未访问节点再启动一次 |
| 递归 DFS 深度 | 节点数极大时递归爆栈（Python 默认约 1000 层），改迭代版 |
| 无向图只登记单方向 | 邻接表残缺，遍历漏节点 |

**排查思路**：遍历结果不对时先打印邻接表核对建图，再打印 visited 集合增长过程；怀疑死循环就检查环上节点是否被标记。

## 五、实际应用与取舍

- **BFS 系**：无权最短路（社交关系"几度人脉"、迷宫最短步数）、层序处理、爬虫按深度调度。
- **DFS 系**：连通分量、环检测（课程表先修矛盾）、拓扑排序（构建/任务依赖）、走迷宫穷举、回溯算法（全排列、N 皇后）的骨架。
- **图存储**：社交网络（邻接表）、地图导航（带权图 + Dijkstra/A*）、网页 PageRank（有向图）、数据库外键依赖、Git 提交历史（DAG）。
- **取舍**：只求"最短步数"用 BFS；要穷举所有路径/检测环用 DFS；带权最短路用堆 + Dijkstra（见[堆](../堆/)的延伸方向）。

## 六、可继续学习的方向

# 栈

## 学习目标

- 理解栈"后进先出（LIFO）"的约束，以及这层约束为什么有价值。
- 能基于数组实现一个栈，理解只在栈顶操作的意义。
- 掌握两个经典应用：括号匹配、函数调用栈，并理解递归与栈的关系。

**前置知识**：[数组](../数组/)（示例用 `list` 做底层）、Python 函数与异常基础。
**适用范围**：所有语言通用；示例语言为 Python。

---

## 一、栈解决什么问题

栈 = 只允许在**一端**（栈顶）插入和删除的线性结构。它不提供新能力，而是主动**收窄能力**：强制"最后放进去的最先拿出来"（Last In, First Out）。很多问题天然具有这种"最近发生的事最先处理完"的结构——函数调用、括号嵌套、编辑器撤销——用栈表达后，正确性一目了然。

## 二、核心原理

### 2.1 只碰栈顶的操作集

```text
入栈 push:      1 → 2 → 3      出栈 pop:
              push 3          ┌────┐
┌────┐        ┌────┐          │ 3  │ ← 栈顶，先走
│ 2  │        │ 2  │          └────┘
│ 1  │        │ 1  │           剩下 2、1
└────┘        └────┘
```

| 操作 | 语义 | 复杂度 |
| --- | --- | --- |
| `push` | 放到栈顶 | O(1) |
| `pop` | 移除并返回栈顶 | O(1) |
| `peek` | 只看栈顶不移除 | O(1) |
| `is_empty` | 是否为空 | O(1) |

用 `list` 实现时约定**列表末尾是栈顶**：`append` 和 `pop()` 恰好都是 O(1)。如果反过来把列表开头当栈顶，每次操作都要搬移整个数组（参见[数组](../数组/)第 2 段）。

### 2.2 括号匹配：栈的经典应用

合法的括号串有两个性质：① 每个右括号和**最近的、还未配对的**左括号类型一致；② 扫描结束后没有未配对的左括号。"最近未配对的"正是栈顶的语义：

```text
扫描 ( [ ) ]：
  (  → 入栈           栈: (
  [  → 入栈           栈: ( [
  )  → 栈顶是 [ ≠ (   → 不匹配！（交叉嵌套非法）
```

**为什么不能用计数器**（数左括号减右括号）：计数只能保证数量相等，无法发现 `([)]` 这种类型交叉错误，也无法发现 `)(` 这种顺序错误。

### 2.3 函数调用栈

程序运行时，每次函数调用都会创建一个**栈帧**（存参数、局部变量、返回地址）压入调用栈；函数返回时它的栈帧弹出，回到调用者。递归没有出口或深度过大时，调用栈被压满，就是 StackOverflow——名字里的 overflow 指的就是这个栈被撑爆。

## 四、常见误区与边界条件

| 误区 / 边界 | 说明 |
| --- | --- |
| 空栈 pop / peek | 必须先判空；返回哨兵值（如 -1、None）会掩盖逻辑错误，明确抛异常更好 |
| 用 list 头部当栈顶 | `insert(0, x)` / `pop(0)` 是 O(n)，破坏栈 O(1) 的意义 |
| 忘记类型校验 | 括号匹配里只比较"有没有括号"不够，还要比较"类型对不对" |
| 递归无出口 | 每个递归函数都要有基线条件（base case），否则栈溢出 |
| 误以为栈能随机访问 | 栈是抽象约束，不是数组；需要中间元素时应换结构（如数组/双端队列） |

**排查思路**：栈相关的错误多半是"空栈还 pop"或"压入和弹出的元素不对称"。在 pop 前断言非空、在调试时打印整个栈内容，能快速定位。

## 五、实际应用与取舍

- **运行时**：函数调用栈、异常展开（traceback 就是调用栈的快照）。
- **算法**：深度优先搜索（DFS，见[图](../图/)）、表达式求值（后缀表达式）、单调栈（下一个更大元素）。
- **工程**：编辑器撤销/重做、浏览器后退、括号/标签校验、JSON/XML 解析器。
- **取舍**：只需要"最近一个"时用栈；需要"最早一个"时用[队列](../队列/)；两头都要用 `deque`。

## 六、可继续学习的方向

- [队列](../队列/)：与栈对称的 FIFO 结构。
- [图](../图/)的第 4 段：DFS 的迭代实现就是显式使用栈。
- 单调栈、表达式求值（逆波兰表示法）——算法主题的高频题。
- Java `Deque` 接口为何推荐用 `ArrayDeque` 当栈而不是 `Stack` 类。

表达式结果原因

      
'5' == 5true字符串转数字 5

      
'' == 0true空串转数字 0

      
'0' == falsetruefalse→0，'0'→0

      
null == undefinedtrue特例：仅彼此相等

      
null == 0falsenull 只与 undefined 宽松相等

      
NaN == NaNfalseNaN 谁都不等，包括自己

      
[] == 0true[] 转原始值 ''，再转数字 0

      
[] == '0'false[] → ''，'' 与 '0' 是两个不同字符串

      
[0] == 0true[0] → '0' → 0

      
[] == []false两个对象比引用，不是比内容

    

    
团队规约：一律用 ===；== 唯一合理用途是 x == null（一口气判 null 和 undefined）。

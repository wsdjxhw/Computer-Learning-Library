# 示例代码 · 初识 TypeScript

## 环境

- Node 18+（`node -v` 检查）
- TypeScript 编译器：不需要全局安装，用 `npx -p typescript@5 tsc`（本机实测 5.9.3）；想常驻可 `npm i -g typescript`，之后直接敲 `tsc`

## 建议的动手顺序

在本目录依次执行（输出均为本机实测）：

```powershell
# 第 1 步：单文件编译，打开产物看"类型擦除"
npx -p typescript@5 tsc --target ES2020 01-类型标注与类型擦除.ts
#   → 生成 01-类型标注与类型擦除.js，用编辑器对比：所有 ": 类型" 和 type 定义都消失了
node 01-类型标注与类型擦除.js
#   → 机械键盘 [ '外设', '办公' ] 含税价 337.86999999999995
#   → { id: 1, name: '机械键盘', price: 299 }

# 第 2 步：按 tsconfig 一次编译全部（02/03 故意含错误，报错是预期现象）
npx -p typescript@5 tsc
#   → 列出 6 个错误（TS2322 / TS2551 / TS2554 / TS7006 / TS2345），但仍然生成了 .js

# 第 3 步：运行产物，看"编译期错误"在运行时的三种下场
node 02-编译期拦截.js     # 前 3 个错误静默出错值，第 4 个当场抛 TypeError 崩溃
node 03-any的连锁反应.js  # any 链一路放行，全部"正常"跑完，但 3307 / undefined 都是错值
```

只检查、不产出（CI / 编辑器常用）：

```powershell
npx -p typescript@5 tsc --noEmit
```

## 文件清单

| 文件 | 主题 | 关键现象 |
| --- | --- | --- |
| `01-类型标注与类型擦除.ts` | 变量/函数/type 标注；类型擦除 | 产物里类型全消失，其余一字不差 |
| `02-编译期拦截.ts` | 4 类典型错误与 tsc 报错格式 | 报错仍产出；错误分"静默错值"和"当场崩溃"两种下场 |
| `03-any的连锁反应.ts` | 显式 any 传染、隐式 any（TS7006）、标注对照 | any 放行后 `: string` 标注形同虚设 |
| `tsconfig.json` | strict + ES2020 + commonjs | `npx tsc` 不带参数时自动读取 |

## 两个约定

1. **变量名带 2/3 后缀**：三个 `.ts` 文件都没有 `import/export`，属于"全局脚本"，一起编译时共享同一作用域——变量重名会报"重复声明"。从知识点 ② 起会引入模块，就没有这个问题了。
2. **产物 `.js` 是生成的**：随时可删（`Remove-Item *.js`），重新编译即可再生；不要手工编辑它们。

# 后端

存放服务端开发相关学习内容，例如：服务端语言与框架、数据库、缓存、消息队列、分布式系统、网络服务、性能优化和后端面试知识。

## 内容规划

### 已有

- `Java/`：**JavaSE 已定稿**（31 个知识点：语言基础、集合、IO流、并发、网络、JVM），说明见 [Java/README.md](Java/README.md)。

### 后续路线（规划中——落地时才建目录）

| 模块 | 预计归属 | 知识点 | 数量 |
| --- | --- | --- | --- |
| 构建工具 | `Java/Maven/` 或 `Java/工具链/` | Maven（依赖/生命周期/多模块） | 1 |
| Spring 生态 | `框架/Spring/` 等 | IoC与Bean生命周期、AOP、事务、SpringMVC、SpringBoot自动配置、MyBatis | 6 |
| Netty | `框架/Netty/` | 事件循环/Pipeline/粘包拆包实战 | 1 |
| MySQL | `数据库/MySQL/` | SQL进阶、索引与执行计划、事务与锁、性能优化 | 4 |
| Redis | `数据库/Redis/` | 数据结构与缓存、持久化与淘汰策略、分布式锁 | 3 |
| 消息队列 | `消息队列/` | 选型对比、可靠投递（RocketMQ 或 Kafka） | 2 |
| 分布式 | `分布式/` | 理论基础（CAP/一致性）、分布式事务、微服务与Spring Cloud | 3 |
| 设计模式 | `设计模式/` | 单例/工厂/策略/代理等高频精选 | 2 |

优先级建议：JavaSE 已定稿收尾，下一步进 Spring 与数据库；消息队列/分布式属于进阶后置。

新增知识点时，先判断是否与已有主题共享稳定的中间分类，再决定目录层级。
